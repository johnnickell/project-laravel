# Framework Starter Product and Walking-Slice Acceptance

## Local authority

This repository owns Laravel-relevant product, walking-slice, architecture, documentation, and build acceptance authority. Ticket status and execution order live in `planning/tickets/`.

Laravel owns service-provider integration, container bindings, HTTP/security composition, and future persistence, queue, realtime, and presentation adapters. Shared behavior is consumed through public Composer packages only; there is no Fight Laravel package and no copied Fight Common or Fight AccessControl Domain/Application source.

## Bootstrap boundary

Bootstrap establishes a governed Laravel foundation that can consume both Fight packages through Composer. Login, persistence, browser journeys, releases, and public-readiness claims require separately adopted local tickets.

## Acceptance boundary

The bootstrap acceptance is the repository-local noninteractive build, hosted build, clean-clone Composer installation, architecture checks, and a clean-clone receipt bound to an immutable commit. Source visibility does not authorize a tag, Packagist publication, template enablement, create-project distribution, or unplanned work.
