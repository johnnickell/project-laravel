# Project context

Fight Laravel Starter is a public-source, Laravel-native application foundation. It composes public Fight Common and Fight AccessControl contracts without becoming their implementation home.

Laravel owns service-provider registration, container bindings, routing, HTTP responses, security, persistence, queues, realtime delivery, presentation, and operations. The bootstrap currently proves only a rendered Hello World HTTP slice through Nginx and PHP-FPM; it is not login, persistence, browser automation, release, or a public-readiness claim.
